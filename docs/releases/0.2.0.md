# Kit 0.2.0 — Claude e Codex na ORCA

- Entrada AGENTS.md compartilhando as regras do projeto com CLAUDE.md, criada na instalação/atualização sem substituir instruções próprias do projeto.
- `kit contexto [caminho]` permite consultar skills, agentes e manuais originais do kit.
- `kit executar <comando> [argumentos]` disponibiliza os comandos do plugin sem depender do PATH ou executável Claude.
- A guarda de workers ORCA verifica modelo, esforço e isolamento também para Codex, recusando nomes de modelos Claude nesse agente.
- A aba ORCA usa o núcleo da mesma árvore do repositório, sem exigir plugin Claude instalado e sem preferir uma instalação antiga da conta.
- A recuperação de instalação interrompida registra AGENTS.md no lock para permitir remoção posterior.

Versões: CLI e aba ORCA **0.2.0**; plugin de orquestração **0.1.111**.

## Atualização local

Com o repositório completo atualizado, carregue `orca/painel-do-kit` como pasta de desenvolvimento na ORCA. Ela usa o núcleo ao lado de `orca/`; distribuir apenas essa subpasta não leva o núcleo junto. Uma nova aprovação pode ser solicitada pela ORCA ao mudar a versão.

## Validação e limites

Validação desta release: gate completo com 1.975 testes passando; painel ORCA com 186 testes passando; manifesto ORCA válido e revisão independente sem bloqueadores.

Foi realizado um teste real de sessão Codex na ORCA: abertura, mensagem, pergunta, resposta com código de confirmação, worker_done e liberação da sessão. O ciclo não alterou arquivos nem abriu PRs.

Os hooks automáticos do runtime Claude continuam específicos dele. Esta release não declara paridade de enforcement automático no Codex nem validação ponta a ponta de PR e merge. As skills globais pessoais migradas nesta máquina não fazem parte desta release.
