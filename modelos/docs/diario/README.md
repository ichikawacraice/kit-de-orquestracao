# Diário

A narrativa do projeto: por que cada coisa foi feita assim, o caso que originou a decisão, o que a medição mostrou. O [roadmap](../roadmap.md) guarda só a linha curta de cada item e aponta para cá.

## Como se escreve

- **Um arquivo por mês**, `AAAA-MM.md`. Cada entrada tem um título com data e uma âncora explícita (`<a id="…"></a>`) que o roadmap pode citar.
- **Cada parte cabe numa leitura:** passou de 150 KB, o mês vira `AAAA-MM-parte-1.md`, `AAAA-MM-parte-2.md`, e assim por diante.
- **Entrada fechada não se reescreve.** Correção entra como entrada nova, com data.
- **Texto de quem não estava lá:** diga o caso concreto, o que foi medido e o que ficou decidido, sem depender de conversa que ninguém mais viu.
