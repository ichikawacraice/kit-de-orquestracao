# Pesquisa

Pesquisa é **snapshot datado**: `AAAA-MM-DD-<assunto>.md`, com a data da leitura no topo e as fontes. Ela **não se edita** depois de escrita. Quando o assunto muda, uma pesquisa nova é escrita ao lado e a velha continua como registro do que se sabia na data dela.

## Regras

- **Pesquisa envelhece.** Quem a usa confere a data antes de confiar, e refaz a medição quando o fato muda o que se vai decidir.
- **Fato lido, não lembrado:** cada afirmação diz de onde veio (link, arquivo e linha, comando e saída).
- **Decisão não mora aqui.** A pesquisa alimenta um ADR ou uma spec; a decisão mora lá.
- **Segredo nunca entra em arquivo,** nem como exemplo.
